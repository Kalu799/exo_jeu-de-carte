# Jeu de carte

Petit jeu cool

## V1 (WIP)

L'ordi tire 5 cartes aléatoires pour le joueur de 1 à 10et classées par ordre croissant.
L'ordi tire ensuite une carte, si le joueur l'a, il click dessus, elle s'efface et il gagne 1pt. Si le joueur ne l'a pas, il click sur "Skip" qui passe et ne gagne pas de pt.
Le jeu se termine quand l'ordi a tiré les 10 cartes et on peut rejouer.
